# 🏰 Disney World REST API (.NET 5 & SQL Server)

API RESTful desarrollada como resolución del **Alkemy C# .NET Acceleration Challenge**. Su objetivo es permitir explorar y gestionar el catálogo completo del universo Disney (personajes, películas, géneros y sus relaciones de participación), incorporando autenticación por tokens JWT y un servicio transaccional de bienvenida por correo electrónico.

---

## 🎯 Características Principales

- **Gestión Completa de Personajes (CRUD)**:
  - Creación, edición, consulta y eliminación de personajes Disney.
  - Registro de imagen, nombre, edad, peso, historia y películas en las que participa.
  - Búsqueda filtrada por nombre (`?name=`), edad (`?age=`) y por ID de película (`?movies=`).
- **Gestión de Películas y Series (CRUD)**:
  - Gestión de título, fecha de creación, calificación (1 al 5), género y elenco asociado.
  - Búsqueda por título (`?title=`), filtro por género (`?genre=`) y ordenamiento cronológico (`?order=ASC|DESC`).
- **Gestión de Géneros Cinematográficos**:
  - Categorización de películas con imágenes representativas y nombres de género.
- **Seguridad & Autorización por Políticas**:
  - Autenticación con **JWT Bearer Tokens**.
  - Políticas de acceso diferenciadas (`[Authorize("user")]` y `[Authorize("active")]`).
- **Servicio de Notificación por Email**:
  - Envío automático de correo de bienvenida tras el registro exitoso del usuario mediante `NetEmailService` y plantilla HTML (`wwwroot/ConfirmEmail.html`).
- **Patrón Repository & DTOs**:
  - Desacoplamiento de la capa de datos usando repositorios especializados (`CharactersRepository`, `MoviesRepository`, `GenreRepository`, `UsersRepository`).
  - Proyecciones ligeras con DTOs (`CharacterViewDTO`, `MovieViewDTO`, `MovieDTO`, `CharacterDTO`).

## 🛠️ Stack Tecnológico

| Capa | Tecnologías |
| :--- | :--- |
| **Framework & Lenguaje** | .NET 5.0, C# 9, ASP.NET Core Web API |
| **Base de Datos & ORM** | SQL Server, Entity Framework Core 5.0 (Code First & Migrations) |
| **Seguridad** | JWT Bearer (`Microsoft.AspNetCore.Authentication.JwtBearer`) |
| **Servicios de Email** | SMTP / SendGrid Client con plantillas HTML dinámicas |
| **Arquitectura** | Repository Pattern, DTO Pattern, Inyección de Dependencias nativa |
